# BTC4HBreakoutPulse v1.2.0 — 精簡單頁布局

GitHub Pages 純前端 Pionex BTCUSDT 永續合約 4H 結構預測頁。

## v1.2.0 本次已完成

1. **刪除重複文字**：「20:00 前動態預測 · 20:00 同時鎖定關卡與機率 · 00:00 驗證」不再佔據主圖上排。
2. **大圖擴寬**：SVG 繪圖區由左 79～右 1006 改成左 61～右 1061（座標系 1200）；右側 NOW 標籤寬 113px、高 25px、字級 11.3；原 40 根改為 48 根 4H K 線，右側留有價格標籤。
3. **機率右置**：大字突破/跌破機率保留，移至資訊列最右側，**刪除進度條**及重複說明。
4. **資訊整合**：左側集中顯示頂齊、底齊價與中軌位置／斜率／平均 K。資料缺失時標示空值，不杜撰。
5. **滑鼠細節**：頂齊、底齊、中軌摘要卡移入顯示完整歷史結構與模型特徵；游標離開自動收合。行動裝置可點擊展開，鍵盤 Tab/Enter/Escape 可操作。
6. **留白最小化**：歷史驗證改收合式區域；1600×900、1440×900、1366×768、1280×720 桌面視窗的完整主畫面不需捲軸；手機使用堆疊版面。
7. **版本可見**：頂端狀態列倒數左方新增 `v1.2.0`。

## 明確保持不變

- Pionex 4H/15M/1D K 線來源、舊版 TradingView Worker 及 Pionex 官方備援。
- Pionex 10 秒即時現價與瀏覽器頁籤價格。
- 中軌之上 → 預測 **突破頂齊**；中軌之下 → 預測 **跌破底齊**。
- 20:00 凍結目標／機率、00:00 結算；凍結後圖表與現價仍繼續更新。
- 4H 水平虛線懸停時，價格標籤跟隨滑鼠，預設不常駐在 NOW 標籤旁。
- v6.0 模型參數沒有重訓或手動調權重：該模型原本以 Binance 現貨九年歷史訓練，派網行情適用性尚待獨立重校準。

## 部署

將覆蓋 ZIP 解壓，保留 `src/`、`tests/` 等路徑，覆蓋至 `BTC4HBreakoutPulse` GitHub 儲存庫 `main` 根目錄。Pages 使用 `main` / `/ (root)`。不需 GitHub Actions。

## 驗證

```bash
node --test tests/*.test.mjs
python tests/compact_layout_browser.py
```

第二項須有 Python `playwright`、本機 Chromium（位於 `/usr/bin/chromium`）。它使用**模擬圖表資料**檢查排版與滑鼠，不代表已對 GitHub Pages 正式行情 API 進行線上測試。
